GAYATHRI BALAMURUGAN — PORTFOLIO

Files:
- index.html: portfolio page
- style.css: blue theme, responsive layout and animations
- script.js: scroll effects, reveal animations, mobile navigation and back-to-top button

How to run:
1. Extract the ZIP file.
2. Open the portfolio folder.
3. Double-click index.html, or open the folder in VS Code and use Live Server.
4. Internet connection is needed for Bootstrap, Bootstrap Icons and Google Fonts CDNs.

Before publishing:
- Confirm the GitHub profile URL in index.html.
- Add your LinkedIn profile URL when confirmed.
- If you want to show project images, add your own photos and link them from the project cards.
